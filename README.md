# Customer Shopping Trends — Data Analytics Project

An end-to-end data analytics project on a retail customer shopping dataset — from raw data cleaning through SQL analysis to an interactive Power BI dashboard and stakeholder-facing report.

---

## 📖 Overview

This project takes a raw customer shopping dataset through the full analytics lifecycle: loading and cleaning the data in Python, engineering new features, persisting it in MySQL, answering business questions with SQL, and visualizing the results in an interactive Power BI dashboard. The final deliverable includes a project report summarizing key findings and recommendations for stakeholders.

---

## 📂 Dataset

- **Source file:** `customer_shopping_behavior.csv`
- **Size:** 3,900 rows × 18 columns (19 after feature engineering)
- **Contents:** Customer demographics (age, gender), purchase details (item, category, amount, season, color, size), engagement signals (review rating, subscription status, previous purchases, purchase frequency), and transaction metadata (payment method, shipping type, discounts, promo codes).

---

## 🛠️ Tools

- **Python** — Pandas, NumPy (data cleaning & feature engineering)
- **MySQL** — data storage and SQL-based analysis
- **SQLAlchemy, PyMySQL** — Python-to-MySQL connectivity
- **Power BI** — interactive dashboard
- **Jupyter Notebook** — development environment

---

## 🔄 Steps

1. **Load & Profile** — Read the CSV with Pandas; inspected structure and quality using `.info()`, `.describe()`, and `.isnull().sum()`.
2. **Handle Missing Values** — Imputed 37 missing `Review Rating` values using the median rating within each product category, preserving category-level rating patterns.
3. **Standardize Columns** — Converted all column names to `snake_case` and renamed `purchase_amount_(usd)` to `purchase_amount`.
4. **Feature Engineering — Age Group** — Created a 4-tier `age_group` column (Young Adult, Adult, Middle-age, Senior) using quartile-based binning (`pd.qcut`).
5. **Feature Engineering — Purchase Frequency** — Mapped the categorical `frequency_of_purchases` field to a new numeric `purchase_frequency_days` column.
6. **Remove Redundant Data** — Verified `discount_applied` and `promo_code_used` were 100% identical across all rows, then dropped the redundant column.
7. **Load to MySQL** — Wrote the cleaned dataset to MySQL (via SQLAlchemy + PyMySQL) as a queryable `customer` table.
8. **SQL Analysis** — Wrote 10 business-question queries directly against the MySQL table (see below).
9. **Dashboard & Report** — Built an interactive Power BI dashboard and a summary PDF report communicating findings and recommendations.

---

## 🗃️ SQL Analysis

10 analytical queries were run against the `customer` table in MySQL to answer specific business questions, including:

| # | Business Question |
|---|---|
| 1 | Total revenue generated by male vs. female customers |
| 2 | Customers who used a discount but still spent above the average purchase amount |
| 3 | Top 5 products by average review rating |
| 4 | Average purchase amount: Standard vs. Express shipping |
| 5 | Do subscribed customers spend more? (avg spend & total revenue, subscribers vs. non-subscribers) |
| 6 | Top 5 products with the highest percentage of discounted purchases |
| 7 | Customer segmentation into New / Returning / Loyal based on purchase history |
| 8 | Top 3 most-purchased products within each category (using `ROW_NUMBER()` window function) |
| 9 | Do repeat buyers (5+ previous purchases) show higher subscription rates? |
| 10 | Revenue contribution by age group |

Techniques used: aggregate functions (`SUM`, `AVG`, `COUNT`), subqueries, `CASE` statements for segmentation, and window functions (`ROW_NUMBER() OVER (PARTITION BY ...)`) for category-wise ranking.

Full query file: [`customer_shopping_behavior.sql`](./customer_shopping_behavior.sql)

## ✅ Results

- Delivered a fully cleaned, deduplicated, and feature-enriched dataset (3,900 rows, 19 columns).
- **Clothing** is the leading category — 1,737 of 3,900 purchases (44.5%).
- Customer base skews male (2,652 vs. 1,248 female).
- Only ~27% of customers are subscribed, and "Every 3 Months" is the most common purchase cadence — an occasional-buyer base with retention upside.
- Average purchase amount: **$59.76**; average review rating: **3.75/5**.
- Discount and promo code usage were found to be 100% overlapping — a data redundancy that was resolved during cleaning.

**Recommendations:**
- Expand marketing toward underrepresented segments (female customers, non-Clothing categories).
- Target the 73% non-subscribed base with subscription incentives to improve retention.
- Run re-engagement campaigns for low-frequency purchase segments.
- Test free-shipping order thresholds to lift average basket size.
- Investigate category-level drivers holding review ratings below 4.5.

Full report: [`Customer_Shopping_Trends_Project_Report.pdf`](./Customer_Shopping_Trends_Project_Report.pdf)

## ▶️ How to Run

1. Clone the repository
   ```bash
   git clone https://github.com/saurabhs009-dotcom/<repo-name>.git
   cd <repo-name>
   ```
2. Install Python dependencies
   ```bash
   pip install pandas numpy sqlalchemy pymysql jupyter
   ```
3. Place `customer_shopping_behavior.csv` in the project root.
4. Set database credentials as environment variables (avoid hardcoding):
   ```python
   import os

   ```
5. Run the notebook to clean the data and load it into MySQL:
   ```bash
   jupyter notebook Customer_Shoppping_trends_.ipynb
   ```
6. Run the SQL queries in `customer_shopping_behavior.sql` against the `customer` table for the business-question analysis.
7. Open `customer_behavior_dashboard.pbix` in Power BI Desktop to explore the interactive dashboard.
